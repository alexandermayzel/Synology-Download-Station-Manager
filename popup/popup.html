Connection

NAS access not allowed

HTTP sends your password and session id unencrypted. Using HTTPS is recommended, so the data travels encrypted.

With HTTPS the certificate has to match the address you entered. If your NAS certificate only covers a host name, use that name instead of the IP address.

Credentials

Six digits from your authenticator app. This device is remembered afterwards, so you should only need it once.

Signs out the current NAS session. Deletes the username, password and device token locally. Device trust saved in DSM remains in place and can be revoked there separately. The NAS address and options remain saved.
Downloads
Folder name relative to a shared folder, no leading slash (e.g. "downloads", not "/downloads" or "/volume1/downloads"). Leave empty to use the default destination already configured on the NAS itself (DSM → Download Station → Settings → General).

Magnet capture inactive

Your preference is saved, but automatic magnet link capture is inactive because Firefox has not allowed access to HTTP and HTTPS websites. Allow access below to activate it.

To recognise clicked magnet links on any website and send them to your NAS, the extension needs access to HTTP and HTTPS websites. This feature is optional. Your choice is saved; capture starts automatically once Firefox allows access. You may need to reload pages that were already open when you granted access.

Adds an archive-password field next to the link list. The extraction itself is the NAS's job: in DSM, under Download Station > Settings > Auto extract, tick Enable Auto extract for downloaded files. Every account sets that for itself, and it is off by default.
Notifications
System messages outside the popup. Problems that stop the extension working at all — signing in, or the destination folder — are reported regardless of these settings.
Tasks
Only runs while there are active tasks — once everything is finished or paused, refreshing stops on its own. For half a minute after an add the list refreshes every 3 seconds regardless, then returns to this setting.
Status order
Drag the handle or use the arrows. Top of the list appears first, so what's still running stays on page 1.
Advanced options
Pings the NAS every 3 minutes so the popup shows "Connected" instantly. Disable to allow HDD hibernation on the NAS when idle.
Reset all settings? Credentials, connection details and every option are deleted. Downloads on the NAS are not touched.
